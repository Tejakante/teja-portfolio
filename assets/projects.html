PROJECT 01

Smart Deforestation Management System

Developed an AI-based satellite imagery system for monitoring forests and detecting deforestation.

  • Developed a system for detecting forest cover loss and deforestation using satellite imagery.
  • Implemented image preprocessing, data augmentation and change detection for identifying vegetation loss.
  • Applied NDVI, NBR and dNBR analysis for vegetation monitoring and fire-affected area assessment.
  • Developed a machine-learning based risk prediction module to identify potential deforestation-prone areas.
  • Built an interactive Streamlit dashboard for visualizing satellite imagery, detection results and environmental insights.
Technologies: Python TensorFlow OpenCV Machine Learning Satellite Imagery Streamlit
